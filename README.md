# HSdeck Murder At Castle Nathria 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 경량화·편집 규칙 (2026-11-14)

- 유지할 공개 API 자료는 `cards.json` 목록, `data/<CARD_ID>.json` 카드 정보·한국 날짜별 상태, `art/` 일반 원화, `golden/` 황금 원화·애니메이션, `frame/` 원본 프레임·텍스처·셰이더입니다. 자산 파일·카드 ID와 자식 카드 연결은 보존합니다.
- 삭제 대상 중복 집계: `render.json`, `history.json`, `*-date.json`. 임시 빌드용으로 생성되더라도 재커밋하지 않습니다. 새 schema/legacy 호환 래퍼를 만들지 않습니다.
- 카드별 파일이 날짜형이 아니라면 한국 시간 실제 최초 사용 가능일 및 이력과 연결을 검증하여 무손실 변환합니다. 사전 클라이언트 탑재일은 제외하며 베타 북미 시간 환산·모험 지구 개방·이벤트 개시·토큰 생성일을 구분합니다.
- 이전에 잘못 기입한 날짜 키는 삭제·통합하고 후속 변경일에는 바뀐 필드만 기록합니다. 표시용 줄바꿈은 `<br></br>`; 원문 근거와 황금/프레임 바이너리는 임의 변형하지 않습니다.
- 재생성에 필요한 `release-policy.json`, `tools/`, `.github/` 및 근거 기록은 실제 참조가 있는 동안 보존합니다.
